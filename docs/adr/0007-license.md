# 0007 — Source-available license (PolyForm Perimeter 1.0.0)

Status: Accepted (2026-10-03) — owner may revisit

## Context
The repository is public. The owner's comparable project (Home Workout) uses PolyForm Perimeter 1.0.0. The spec forbids monetization and asks for license clarity.

## Decision
Use the same license as Home Workout for consistency. Third-party code/assets must be compatible and reviewed (`pnpm check:licenses`, `docs/third-party.md`).

## Consequences
The project is "source available", not OSI open source. If outside contributions or reuse should be encouraged, a permissive or copyleft license (e.g. MIT, MPL-2.0, AGPL-3.0) would be the alternative — a decision for the owner.
